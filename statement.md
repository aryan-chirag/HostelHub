# Project Statement

## Project Title

HostelHub - Hostel Management System

## Problem Statement

Hostel management involves maintaining student records, room information, complaints, visitor details and leave requests.

When these activities are handled manually or separately, maintaining, finding and updating records can become difficult.

HostelHub provides a simple Java-based system that organizes these hostel operations in one application and maintains the associated records using local CSV files.

## Scope of the Project

The project covers the basic management of hostel-related records.

The system includes:

- Student record management
- Student room allocation and removal
- Room creation and availability checking
- Room occupancy tracking
- Complaint registration and resolution
- Visitor entry and exit records
- Student leave requests and status updates
- Basic hostel analytics
- File-based data storage
- Basic input validation and error handling

The project focuses on hostel management operations and does not include online payment systems, biometric authentication, web-based access or external database servers.

## Target Users

- Hostel students
- Hostel wardens
- Hostel administrators
- Hostel management staff

## High-Level Features

### Student Management

The system maintains student information, allows student records to be added, viewed, searched and removed, and supports room assignment.

### Room Management

The system maintains room capacity and occupancy and allows users to view available rooms and assign students based on room capacity.

### Complaint Management

Complaints can be registered, viewed and marked as resolved while maintaining their category, description, priority and status.

### Visitor Management

Visitor entry and exit information can be recorded and viewed along with visitor details and their associated student.

### Leave Management

Leave requests can be submitted, viewed and updated with their reason, leaving date, return date and status.

### Analytics

The system provides basic hostel statistics including the number of students, rooms, complaints, visitors, leave requests, occupied beds and available beds.

### Data Persistence

Hostel records are stored in CSV files and loaded when the application starts so that saved records remain available across program runs.

## Project Objectives

1. Maintain hostel records in an organized manner.
2. Simplify common hostel management operations.
3. Reduce the difficulty of manually maintaining hostel information.
4. Provide a simple menu-driven system for hostel-related operations.
5. Apply Java and Object-Oriented Programming concepts to a practical problem.
6. Use Java Collections and file handling to manage and persist application data.
7. Provide basic input validation and error handling.
